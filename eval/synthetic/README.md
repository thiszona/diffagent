# Synthetic eval corpus

Everything here is made up for `diffagent-eval`: the code, the repository (`acme/shop`),
the commits (repeated digits), the PR, the ticket (`PROJ-123`) and every reply. Nothing
is taken from a real repository or a real person. It is small on purpose: enough for
every subcommand to run, and for the eval's tests, not to measure review quality.

`eval/README.md` lists each file and how to replace the corpus with your own labels.
